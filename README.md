# starbucks-nutrition-data

Data and docs for the free Starbucks calorie calculator.

## About

This repository documents the Starbucks calorie calculator project — a free nutrition tool that helps you look up calories and nutrition facts for Starbucks drinks and plan lighter swaps.

## Try the calculator

Use the free calculator here: [Starbucks Calorie Calculator](https://starbucks-calorie-calculator.us/)

Or visit directly: https://starbucks-calorie-calculator.us/
